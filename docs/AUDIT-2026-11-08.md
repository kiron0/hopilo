## Fixed findings

| Priority | Defect / impact | Fix and evidence |
| --- | --- | --- |
| High | Redacted `.handoff` exports still bundled original text attachment bytes. | Generate sanitized UTF-8 blobs; recompute sizes/hashes; update message file references. Archive round-trip regression checks shared attachments and verifies that exported metadata/bytes contain no original test secret. Source data stays unchanged. |
| High | Private-key redaction removed the PEM header but left key material. | Match complete PEM blocks, including RSA/EC/OpenSSH/encrypted forms. A truncated block is redacted through end of input. Regression verifies body removal and surrounding-text preservation. |
| High | JSON/archive metadata and missing/file block descriptions could retain secrets. | Extend scanning/redaction to titles, context fields, tags, source metadata, filenames and missing descriptions. Regression checks serialized output and a subsequent scan. |
| High | Browser drafts bypassed configured file exclusions and custom secret rules. | Load stored rules in the native host; remove excluded file content before rendering; scan using the configured redactor. Integration regression preserves the original library attachment. |
| High | Old async responses could repopulate invalidated cache, including deleted session data. | Guard writes by invalidation epoch, library tick and current request identity. Allow stale prefetch entries to refresh after library changes. Tests cover reversed completion order, explicit invalidation, empty-cache contamination and request deduplication. |
| Medium | File timestamps rounded to seconds caused fast updates to be skipped; lexical comparison mishandled fractional timestamps/offsets. | Preserve filesystem nanoseconds; compare parsed instants; allow metadata-only upserts to advance fractional timestamps. Regression covers one-nanosecond changes and equivalent timezone offsets. |
| Medium | Renamed sessions were reparsed on every sync because custom titles never matched discovered titles. | Include the existing `title_edited` flag in origin state; ignore discovered title differences when the user owns the title. |
| Medium | Parent SQLite title databases could commit to WAL without changing the main DB fingerprint. Antigravity also cached external titles with transcript contents. | Include parent WAL metadata in discovery fingerprints; apply current Antigravity database titles after transcript memoization. Tests cover WAL updates and title changes without transcript writes. SQLite documents commits being appended to WAL before checkpointing: [WAL behavior](https://sqlite.org/wal.html). |
| Medium | Discovery cache could mix adapters using the same root or retain a transient discovery error as an empty successful listing. | Key by adapter plus root; cache only successful discoveries. Sort fingerprint traversal for stable ordering. Metadata-only successful syncs now notify clients; later failures do not repeatedly rearm change notifications. |
| Medium | File size checks ran before unbounded reads; plain chat exports had no equivalent limit to zipped exports. | Bound actual file reads to limit + 1; cap zipped/plain chat-export reads and reject oversized raw exports before allocation. Test uses a sparse oversized file. |
| Medium | Same-origin browser downloads called `arrayBuffer()` before enforcing limits. Invalid URLs aborted capture; base64 padding overcounted file sizes. | Share a streaming capped reader between content/background code, cancel oversize streams, honor remaining capture budget, count decoded bytes accurately and retain malformed references as missing files. Four regressions cover stream bounds, exact limits, padding and malformed URLs. |
| Medium | Predictable `.part` export paths could overwrite unrelated files or collide between writes. | Use unique same-directory temporary files, sync content, atomically persist/replace. Regression checks replacement and preservation of an unrelated `.part` file. |
| Medium | Malformed non-ASCII attachment hashes could panic during archive filename slicing. Unknown archive versions were accepted. | Validate hash shape before import/export path generation; reject unsupported archive versions. Regression checks malformed Unicode digests return errors. |
| Low | Failed extension handoffs updated “last copied”; settings-load errors were unhandled; error formatting could itself throw. | Update copy timestamps only for successful handoff states; surface settings-load failure; provide safe error string fallback. Failed/successful handoff regression included. |
| Low | README and architecture docs advertised nonexistent ChatGPT browser capture. | Correct descriptions to distinguish supported browser adapters from ChatGPT account export imports. |

## Performance findings and next work

These are static scaling risks, not measured production bottlenecks. No speedup percentages are claimed.

| Area | Evidence / constraint | Next measurement or change |
| --- | --- | --- |
| Library IPC | `list_sessions` returns/clones every visible row. Views filter/paginate afterward. | Benchmark 1k/10k/100k sessions; add DB-side filtering/pagination with stable ordering if IPC dominates. |
| Import memory | Chat exports parse one full JSON tree; listing and importing parse again. The 1 GiB cap is still a large memory budget. Raw handoff JSON, some adapter JSON and Zed decompression also need a unified limit policy. | Measure peak RSS; stream conversations, cache validated import metadata, apply parser/decompression budgets. |
| Transcript search/rendering | Debounced search still enumerates all occurrences; jumping deep expands all preceding messages. | Stress-test a long synthetic transcript; use a windowed list and capped/lazy match indexing if needed. Preserve keyboard navigation. |
| Cache identity | Query keys derive from `loader.toString()` plus dependencies. Correctness depends on callers providing every captured parameter. | Replace with explicit typed query keys before expanding data-loading APIs. |
| Export memory | Archive construction holds rendered documents and blobs together; ZIP-of-formats creates more copies. | Measure attachment-heavy exports; stream to a temporary file and deduplicate shared blobs. Sanitized blob buffers are now allocated only for formats that need them. |
| Desktop GPU | `Flow` schedules animation frames while mounted; hidden-window behavior depends on WebView throttling. | Profile idle/hidden energy use; explicitly pause animation on visibility events if native throttling is insufficient. |

Exact preview should also unify native-host and desktop framing/defaults. Present token budgets are estimates, not tokenizer-exact counts; opaque image/PDF/binary attachments are not text-scanned or automatically sanitized.
